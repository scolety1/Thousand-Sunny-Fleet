# TSF V1 Structured Fulfillment Policy Hotfix

This packet records Tim's V1 decision: generic text responses are structural-only and non-admissible.

`TEXT_RESPONSE_V2`, legacy freeform text, and equivalent arbitrary-prose results may be transported, preserved, displayed, and audited. They cannot independently produce semantic fulfillment, verifier GREEN, admission, a success receipt, or a fulfilled UI state.

Admissible V1 paths are deterministic contracts:

- `EXACT_LITERAL_V1`, with independent exact equality and identity verification.
- `GENERAL_RESULT_V2` with the closed `STRUCTURED_ANALYSIS_V2` deliverable profile and independent type, cardinality, structure, evidence, and identity checks.
- Existing deterministic contracts whose completion is independently mechanically verifiable.

The hotfix adds no LLM semantic judge and no semantic, verifier, admission, routing, mission, approval, merge, or production authority.

Recovery uses the same mission-bound contract chosen before the interrupted run. The real recovery fixture therefore requests the closed structured-analysis deliverables it expects to admit. A separate generic recovery fixture proves that arbitrary text is still preserved and explicitly not admitted.

The closed general-result schema accepts the canonical `STRUCTURAL_TEXT_ONLY_V2` preservation representation. That compatibility value grants no semantic success, verifier GREEN, admission, receipt, or fulfilled UI authority.

Publication requires the exact candidate, targeted soak V5, full V1 acceptance, fresh Tester GREEN, and fresh Auditor publication acceptance. Merge remains Tim-only.

`SHA256SUMS.txt` uses canonical UTF-8 text with LF line endings. The packet self-check normalizes Windows text materialization to that domain before hashing; it does not ignore, trim, or rewrite any other content.

The committed packet deliberately distinguishes pre-final proof from final acceptance. `VALIDATION.json` does not claim final GREEN before the final evidence amendment is cleanly committed and independently rerun.
